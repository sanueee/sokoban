# Sokoban

**Авторы:** kahooso & sanueee  
**Стек:** C11 · raylib · SQLite3 · CMake (macOS / Windows)

Классическая головоломка Sokoban с процедурной генерацией уровней, профилями игроков и встроенным решателем на базе Push-based A\*.

## Возможности

- **Процедурная генерация** — 3 уровня сложности, обратная генерация (`ReverseSolve`) и кроссплатформенный ГПСЧ `xorshift32`
- **Решатель** — Push-based A\* с канонизацией позиции игрока, эвристикой Манхэттена и отсечением дедлоков (угловых и 2×2)
- **Игровой процесс** — неограниченный `Undo`, профили и статистика сессий в SQLite, две музыкальные темы
- **Бенчмарк** — детерминированный прогон `sokoban_bench` с валидацией решений (`BASE_SEED = 6769`)

## Управление

| Клавиша | Действие |
|---|---|
| `WASD` / стрелки | Движение |
| `Z` | Отменить ход |
| `R` | Перезапустить уровень |
| `ESC` | Пауза |
| `Cmd` / `Ctrl + B` | Запустить решатель |

## Уровни сложности

| Сложность | Поле | Ящиков | Обратные ходы |
|---|---|---|---|
| Easy | 9×9 – 11×11 | 3–4 | 30 |
| Medium | 11×11 – 12×12 | 5–6 | 60 |
| Hard | 13×13 – 14×14 | 7–8 | 100 |

## Сборка и запуск

Зависимости: **CMake**, **raylib**, **sqlite3**.

```bash
# Первичная настройка build/ (один раз)
cmake -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo

# Сборка из корня проекта
make sokoban          # игра -> build/sokoban
make bench            # бенчмарк -> build/sokoban_bench
make clean            # очистка артефактов в build/
```

Запуск игры и бенчмарка (из `build/`, чтобы корректно находились `../assets` и `../tests`):

```bash
cd build
./sokoban
./sokoban_bench 5     # по 5 уровней на сложность -> ../tests/bench_results.csv
```
